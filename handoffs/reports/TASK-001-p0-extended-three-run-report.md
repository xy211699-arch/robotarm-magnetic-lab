- 三个不同seed得到相同最终覆盖率和几乎相同活动范围，说明当前自动动作周期是确定性的
  局部往复策略；seed没有引入空间探索差异。
- 覆盖在约80个动作后不再明显增长，后续动作主要重复观察同一胃壁区域。
- 三轮没有`ACTION_MASKED`、规划失败、执行超时或胃壁碰撞，故本轮未达标不能归因于
  安全边界过严。
