# 原子动作层第二阶段实施方案

## 1. 阶段目标

第二阶段将第一阶段已经通过设备级验证的11个短动作，扩展为可供后续VLA/RL使用的
SMDP数据接口，并在平桌环境中量测每个动作引起的胶囊自然响应。

本阶段不训练Actor，不用胶囊真值闭环修正动作，也不把胶囊响应偏差升级为
`HARD_FAILURE`。设备执行结果和胶囊动作效果必须继续保持两套独立语义。

## 2. 实施顺序

### 2.1 建立1 Hz SMDP动作边界

新增动作边界管理器，统一以下时序：

- 物理引擎：240 Hz；
- 原子动作执行器：20 Hz；
- 策略RGB与Actor决策：1 Hz；
- Actor只在当前动作达到`DONE`且有一张新的1 Hz RGB后才能提交下一动作；
- 动作执行期间到达的新RGB只更新单帧缓存，不触发抢占；
- 动作提前完成时保持最终命令，等待下一张真实新图像；
- 动作超出一个图像周期时记录实际持续时间，完成后再开放下一决策边界；
- 只有边界管理器可以调用`acknowledge_result()`，防止同一动作张量被自动重复执行。

需要覆盖重复同一动作、图像提前到达、动作延迟完成、回合reset和
`HARD_FAILURE`终止五类时序测试。

### 2.2 冻结Actor transition协议

每个高层transition包含：

- `rgb_t`及其真实采集时间戳/帧ID；
- 最近动作历史；
- 机器人九轴`q/qd`；
- 外磁体位置与姿态；
- 当前11维动作掩码；
- 本次动作ID、请求/开始/结束时间和实际持续时间；
- `DONE`或`HARD_FAILURE`；
- 动作结束设备状态；
- 下一张新图像`rgb_t1`。

Actor协议禁止包含胶囊位姿、速度、接触、磁力、深度、胃部区域或动作效果误差。
数据校验器必须通过字段白名单阻止这些量进入Actor导出数据。

### 2.3 建立独立的特权评价/Critic记录

同一transition另存一份按`request_id`关联的特权记录，用于训练Critic、奖励和离线分析：

- 胶囊起止位姿、线速度、角速度和磁性轴方向；
- 接触力、接触保持率、离地高度和异常跳起；
- 胶囊处磁力/磁矩及外磁体场强；
- 动作方向投影、横向漂移、姿态变化和净位移；
- 仿真初始条件、随机种子和物理参数版本。

特权数据不能参与执行器完成判定，也不能合并进Actor observation group。

### 2.4 平桌11动作物理量测

为每个动作建立独立可视化测试，并从多个初始姿态、位置和随机种子重复运行：

| 动作 | 主要连续量测 |
|---|---|
| `HOLD` | 位姿漂移、速度、接触稳定性 |
| `TILT±` | 有符号倾角变化、轴向误差、响应延迟 |
| `AZIMUTH±` | 包角后的有符号方位变化、倾角保持误差 |
| `ROLL±` | 命令方向投影位移、横向漂移、滚动/滑动比例 |
| `TURN±` | 有符号航向变化、位置漂移、倾角变化 |
| `APPROACH/RETREAT` | 场强/磁力变化、胶囊位移、接触与离地趋势 |

建议第一轮每个“动作×初始状态”至少运行30个种子。先使用少量确定性样例做功能
验收，再批量运行统计。统计输出分布、均值、标准差、分位数和方向一致率，不输出
`SUCCESS/NO_EFFECT`等离散效果等级。

### 2.5 连续奖励和离线标签

只构造连续量：

- `TILT/AZIMUTH/TURN`：期望方向上的角度变化减去正交漂移；
- `ROLL`：期望方向净位移减去横向漂移、滑移和过高速度惩罚；
- `APPROACH/RETREAT`：期望磁耦合变化及接触稳定项；
- 全动作：时间成本、能耗代理量、异常跳起和特权碰撞惩罚。

这些量只进入训练奖励、Critic或离线报告，不改变动作层的`DONE/HARD_FAILURE`。

### 2.6 动作参数标定

根据量测分布调整倾角/方位增量、Ball耦合转向轨迹、ROLL位移、APPROACH距离和
动作持续时间。每次修改必须版本化为独立参数集，并重新运行11动作设备安全回归。
不应通过读取实时胶囊姿态来提高单次动作效果。

### 2.7 硬失败containment验证

用故障注入分别触发：非法/被屏蔽动作、非有限状态、关节/工作区越界、XRDF路径
冲突、控制器断连和跟踪超时。确认系统保持最后安全目标、返回`HARD_FAILURE`并终止
回合。自动撤离和`RECENTER`仍不启用，必须留到独立安全验证阶段。

## 4. 验收门槛

1. 1 Hz决策边界不丢帧、不抢占、不自动重复动作，所有时间戳单调且实际持续时间正确。
2. Actor transition字段白名单测试通过，胶囊真值和特权物理量无法进入Actor数据。
3. 11个动作均有可视化测试、结构化记录和统计报告；正常样例设备侧全部到达`DONE`。
4. 胶囊响应以连续分布呈现，方向错误或效果较弱不会触发设备硬失败。
5. 所有故障注入均保持最后安全目标并结束回合，不执行未经验证的自动恢复。
6. 第一阶段11动作回归和原有9维任务回归继续通过。

## 5. 阶段交付物

- 可复用的1 Hz SMDP边界管理器；
- Actor transition与特权Critic记录双通道协议；
- 11个动作的平桌可视化测试与批量采集入口；
- 动作响应统计报告和版本化参数集；
- 故障containment验证报告；
- 为下一阶段胃部环境迁移和Actor–Critic训练准备好的数据接口。
