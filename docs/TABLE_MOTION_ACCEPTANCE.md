1. 新建不含胃部的平整桌面场景，保留机械臂、ASM、磁场和被动胶囊。
2. 注册独立 Isaac Lab 单环境任务，避免改动原胃部训练任务。
3. 建立平桌接触基线：静置、15 mm 跌落、滑动衰减和防穿透检查。
4. 验证圆柱永磁体沿胶囊局部 `+Z` 轴向充磁，并扫描 Ball 可达磁场方向。
5. 实现有限尺寸磁铁模型的“期望磁场方向 → Ball 关节”数值逆映射。
6. 实现固定倾角下的方位旋转开环轨迹。
7. 实现从直立到侧卧滚动态的五次平滑开环轨迹。
8. 实现沿胶囊长轴的被动滚动：Ball 保持轴向场，机械臂平移产生横向梯度力，
   桌面摩擦产生滚转力矩。
9. 建立五个可视化验收脚本、统一日志、自动判据和本报告。

## 物理原理边界

内部圆柱磁铁与胶囊长轴同轴且为轴向充磁。均匀磁场的磁矩
`tau = m × B` 永远垂直于磁矩，因此不能直接产生绕胶囊长轴的力矩。长轴运动
不能通过“让 Ball 绕磁铁自身轴旋转”实现；该旋转在理想轴对称磁场中没有效果。

本实现用机械臂移动外部磁铁，产生沿桌面的磁场梯度力。胶囊发生平移时，接触
摩擦在胶囊中心形成绕长轴的被动滚转力矩。测试同时比较平移距离与
`半径 × 累积长轴转角`，防止把纯滑动误判为滚动。

## 人工可视化验收

从项目根目录逐项运行：

```bash
./run_isaaclab.sh -p scripts/table_motion/test_01_baseline.py
./run_isaaclab.sh -p scripts/table_motion/test_02_axial_field_scan.py
./run_isaaclab.sh -p scripts/table_motion/test_03_tilt_azimuth.py
./run_isaaclab.sh -p scripts/table_motion/test_04_upright_to_side.py
./run_isaaclab.sh -p scripts/table_motion/test_05_long_axis_roll.py
./run_isaaclab.sh -p scripts/table_motion/test_06_composite_motion.py
```

观察重点：

- 测试 01：胶囊静置不漂移，跌落接触后不穿透，初速度很快被摩擦耗散。
- 测试 02：胶囊不受磁力，磁场线随 Ball 姿态改变。
- 测试 03：胶囊保持倾斜并改变水平观察方位，持续贴桌。
- 测试 04：胶囊平滑由竖直姿态倾倒到近水平姿态，无瞬时姿态跳变。
- 测试 05：红色滚动标记应随胶囊绕长轴转动，同时胶囊沿桌面移动；不应跳起。
- 测试 06：胶囊在同一次连续运行中依次完成“侧躺→直立→30°倾斜整圈→
  直立→侧躺→沿世界+X滚动100 mm”，阶段间不重置胶囊。

需要胶囊相机预览时追加 `--capsule_camera_view`；需要接触调试标记时追加
`--contact_debug`。自动化无窗口验证使用：

```bash
--visualizer none --no-realtime
```
