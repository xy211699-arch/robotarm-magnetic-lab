# 下一阶段任务

## 胃部视觉当前进展

[DINOv3 初次相机数据线性探测](../experiments/dinov3-gastric-20261120/README.md)已交付两项仿真实验的划分、模型、测试结果与可视化。病灶分类用新版 200 张原图，按采集组与局部视角块留出。距离回归从 411 张候选分箱保留 312 张原图，按关联采集组留出。两项任务仅对训练数据使用增广。

RADIOv2.5-B 与 SigLIP2-B 已沿用相同划分完成两项验证与测试。三个编码器在病灶留出视角上均为 35/35，距离回归表现随误差指标和距离区间而变。[三编码器对比](../experiments/gastric-encoder-comparison-20261123/README.md)

## 独立来源评估

肿起和溃烂各只有一个采集来源。需要补充独立病灶区域、采集组或场景，复核图像标签与目标区域，再按独立来源固定训练、验证和测试。正常胃壁的数据量应与两类病灶之和相匹配。当前同批次结果用于记录模型在已见采集来源的留出视角上的表现。

## 距离数据与真值

当前回归测试包含 64 张留出原图，部分场景跨集合。正式方案的 500 张原图目标仍待完成。后续补充源数据并区分采集组与场景，独立回放仿真场景核对光轴首交点距离，复核误差在各距离区间的变化。[DINOv3 实验方案](design/2026-11-17-dinov3-gastric-vision-linear-probe.md)

## 多模态接入

继续以验证后的视觉表示为基础设计异步观测、技能接口、执行时序及历史融合架构。效果预测与机器人控制验收仍需单独开展。
