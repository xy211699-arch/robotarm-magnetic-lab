# 下一阶段任务

## 当前任务

当前任务为 [胃部视觉编码器Linear Probe对比实验](design/2026-10-25-gastric-vision-linear-probe.md)。对RADIOv2.5、DINOv2和SigLIP2冻结官方预训练权重，分别训练线性分类头与回归头，评估仿真病灶特征识别和胃壁距离预测，为后续多模态操作效果预测选择候选视觉骨干。

用户已明确该任务为下一阶段方案，本次只整合并提交文档；数据采集和模型评测尚未开始。三个模型的具体checkpoint、特征读取方式、距离标签定义和划分规则需在实施配置中明确，不把尚未定义的细节写成已冻结结论。

## 阶段一：数据采集

基于现有Isaac Lab胃部磁控胶囊仿真，分别建立约300—500张病灶特征图像和约300—500张胃壁距离图像，均使用自有仿真数据。病灶图像具有正常/异常或具体类别标签，距离图像对应同一相机帧的几何距离真值；采集覆盖不同位置、姿态、观察距离与场景条件，控制近重复图像。

交付两套图像及标签、采集脚本、数据说明和统一train/validation/test清单。按轨迹或采集组控制相关样本跨划分泄漏，具体分组与比例在采集前登记。

## 阶段二：模型评测

三个编码器使用相同数据划分、训练与选择流程。病灶分类报告Accuracy和Macro-F1，距离回归报告MAE和RMSE，另记录特征提取耗时与显存开销；特征提取保持冻结且使用各checkpoint对应的官方预处理，具体配置可追溯。

交付三编码器×两任务的六组结果、统一特征提取和线性探测代码、对比表与必要可视化、分析报告及候选骨干建议。本阶段不微调视觉编码器，不做Zero-shot或下游动作预测。

## 结论边界与后续

仿真病灶评测反映合成场景特征的区分能力，不等同临床诊断效果；单帧距离回归也不能直接推断跨场景空间理解。具体协议、待明确项和复用入口见 [完整方案](design/2026-10-25-gastric-vision-linear-probe.md)。

完成本阶段后，根据结果形成视觉骨干候选，再结合本地多模态设计明确观测、技能与执行时序。更完整的历史融合架构仍是待设计事项，本阶段不因旧示意图而预先固定DINOv2或GRU/Transformer。
