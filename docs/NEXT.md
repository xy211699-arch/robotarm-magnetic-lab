# 下一阶段任务

## 当前任务

当前开展 [DINOv3胃部视觉表征Linear Probe实验](design/2026-11-17-dinov3-gastric-vision-linear-probe.md)。冻结DINOv3官方预训练视觉编码器，分别训练线性分类头与回归头，评估病灶特征识别与胃壁距离预测，为后续多模态操作效果预测提供依据。

当前处于数据准备阶段，已有 [初步病灶样本](https://github.com/xy211699-arch/robotarm-magnetic-lab/releases/tag/gastric-lesion-classification-v1) 供流程检查。本次已离线整理并核验磁盘采集证据，交付独立的[候选数据预发行版](https://github.com/xy211699-arch/robotarm-magnetic-lab/releases/tag/gastric-candidates-20261119-v1)，状态与索引见[交接报告](../handoffs/reports/GASTRIC-DATA-UPLOAD-20261119.md)。完整分类候选为正常100、肿起旧50+新50、溃烂旧50+新50，全部语义标签待复核；两个200张版本共享正常100张。距离经范围与保守去重检查为411张技术候选，至少还缺89张，正式验收未完成。标签口径、原分辨率复核、独立分组和GPU首交点回放待处理；特征提取与训练另行安排。

## 阶段一：数据采集

先统计仿真中病灶特征种类，每种病灶共采50张，覆盖不同视角和距离；正常胃壁图像总数与全部病灶图像总数相等。相机直接导出图像，画面不含软件界面，采集时同步标注并保留场景、轨迹、相机位姿、时间和配置。

明确相机到胃壁距离的几何定义、单位及无效规则，从不同位置采集500张图像，逐张配对真实距离。按采集轨迹或场景分组，形成固定的训练、验证、测试清单，控制近重复帧泄漏。

阶段交付包括病灶类别清单、两套图像与标签、采集标注脚本和配置、元数据、质检与数据说明，以及划分清单。病灶数量按实际类别清单统计，正式标签映射与距离定义在训练前固定。

## 阶段二：DINOv3评测

在配置中明确一个DINOv3官方checkpoint、权重身份、官方预处理、特征层与池化，并固定线性头训练和验证选择流程。病灶分类报告Accuracy和Macro-F1，距离回归报告MAE和RMSE，另记录特征提取耗时与显存。

交付DINOv3特征提取及Linear Probe代码、病灶分类和距离回归两组实验记录、计算成本、可视化及适用性报告。本阶段仅训练线性头，不微调编码器，不开展Zero-shot或动作预测。

## 验收与后续

数据验收核对每类病灶50张、正常样本与病灶总量相等、距离图像500张、标注与采集信息完整，以及分组划分可追溯。评测验收核对编码器冻结、四项主指标、成本口径和可复现记录，具体协议见 [完整方案](design/2026-11-17-dinov3-gastric-vision-linear-probe.md)。

根据DINOv3在当前仿真数据上的实际表现，形成后续多模态模型接入建议。异步观测、技能接口、执行时序及历史融合架构仍需独立设计。
