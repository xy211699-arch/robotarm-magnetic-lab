# 存储与证据

## 输入和源码

Git保存源码、测试、小型配置、批准合同、精选报告和身份清单。外部机器人USD、vendor、原始数据、冻结位姿库和权重在已确认路径读取，不为整理仓库覆盖原件。历史已跟踪二进制与附件保留，不借本批改造批量删除或改成另一种存储。

## 输出和持久化

现有默认工件规则见 [ARTIFACT_STORAGE](../ARTIFACT_STORAGE.md)，既有仿真脚本继续使用其路径解析器。新增new-run默认写当前副本artifacts/research，这是独立记录区，不接管原监督器的jobs；可用--output-root显式指定已确认持久盘。不要假定/tmp或临时worktree可永久保存，先核对真实路径、挂载和符号链接。

原始日志、录像、checkpoint和完整运行结果不进入普通Git。报告引用绝对运行路径、代码身份、字节数及SHA-256；清单不等于接收侧已核验，只有实际读取并重算后才能称字节通过，哈希一致不证明科学结论。

## 写入和恢复

每次运行使用唯一目录，不覆盖旧结果；失败记录保留，人工修复后另建记录并关联父运行。命令执行前确认输入输出不会重合，未经授权不清理用户草稿或旧目录。恢复操作只针对明确文件，避免硬重置、批量删除和自动重跑。
