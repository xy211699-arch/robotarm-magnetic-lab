# 项目介绍与暂定研究方向

## 研究目标

当前关注磁控操作中如何利用有限、异步的多模态反馈判断继续局部操作是否值得，并选择合适的操作方式。图像、接触信号、机构状态和实际执行历史形成历史表征，对有限候选技能的短时任务效果与接触后果进行估计，再选择内部调整、机械臂局部重定位、解除并重建接触或等待新观测。

历史表征不等于精确内部状态。信息不足应允许“不足以判断”，不能强制归为必须重配置；候选集中较低代价也不等于全局最小重配置。任务误差、接触事件、预测范围与代价采用位移、接触转换次数还是耗时，需要后续设计明确。

## 学习与传统执行

暂定学习模块负责历史编码及动作条件的操作效果预测，规则层负责目标阶段、候选比较和方式选择。传统控制负责轨迹、伺服、工作空间与速率限制、互锁、接管、缓存指令作废、中断及超时退出，接触事件可以触发重新评估。这是目标分工，当前实现范围见 [已有实现](IMPLEMENTED.md)。

## 方案未统一之处

正文表格提出DINOv2 ViT-S/14、压阻触觉MLP、机构动作MLP、结构化目标Embedding、两层256维GRU和动作条件双输出预测头；配图则将历史融合写为四层256维四头Transformer Encoder。当前不选择其中一种，不冻结维度、微调范围与训练协议，等本地方案进一步说明。

材料还提到压阻传感器制作与标定、仿真实物配对数据、技能标定迁移，以及珞石机器人和Apex Hand。它们是后续线索，不代表当前已接入；零散TENG笔记不足以确定正式传感方案。右手环境重配置被放在后续研究阶段，不据此扩展本次实施。
