# Robotarm Magnetic Lab

## 项目介绍

本项目研究磁控操作中的多模态反馈与操作方式选择。当前暂定方向是根据图像、接触信号、机构状态和实际动作历史预测候选操作效果，再选择内部调整、局部重定位、接触重建或等待；具体架构以后续本地设计方案为准，见 [项目方向](docs/PROJECT.md)。

## 已有实现

仓库已有机械臂与外磁体仿真、新胃场景、磁场驱动、安全轨迹执行、相机与覆盖计算，以及可行性验证训练代码。这些是可复用基础，不代表新方向的触觉感知、效果预测和技能选择已实现，详见 [实现边界](docs/IMPLEMENTED.md)。

## 下一阶段任务

下一步先接收并版本化本地设计，明确观测与动作的映射范围、时序、候选技能和验收，再拆分团队任务。旧A/B/C/D对比仅作历史可行性验证，不再是当前主线或默认待办，见 [下一阶段](docs/NEXT.md)。
